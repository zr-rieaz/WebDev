# 🌐 Web Design & Development - 1

> A modern, responsive, offline-first Progressive Web App (PWA) digital textbook for **Web Design & Development - 1 (Subject Code: 28544)**, fully aligned with the **BTEB Probidhan-2022** curriculum.

---

## 📌 Features

- 🎯 **Full Syllabus Coverage:** Comprehensive coverage of all 6 Theory Units and 6 Practical Experiments.
- 📱 **Progressive Web App (PWA):** Installable on desktop and mobile devices with full offline functionality.
- 🔄 **Auto-Resume Reading:** State persistence via `localStorage` that saves scroll position, selected unit, and active tab automatically upon refresh.
- 📐 **Dual-Track Navigation:** Right-side sliding navigation drawer with persistent toggle tabs for **Theory** and **Practical** content.
- ⚡ **Interactive Code & Tools:** Integrated UI/UX guidelines, W3C standards, responsive frameworks, PHP, AJAX, JSON, and database CRUD operations.

---

## 📑 Syllabus Overview

### 📘 Theory Units
1. **Web Technology and Industry Requirement**
2. **UI / UX and Markup Language**
3. **Responsive Website and Framework**
4. **Client-Side Scripting Language (JavaScript & jQuery)**
5. **Server-Side Scripting Language (PHP)**
6. **Data Manipulation (AJAX, JSON, APIs & CRUD)**

### 🧪 Practical Experiments
1. **Interpret Web Technology and Industry Requirement**
2. **Convert UI/UX to Markup Language**
3. **Develop Responsive Website Using Framework**
4. **Develop Website Using Client-Side Scripting Language**
5. **Develop Website Using Server-Side Scripting Language (PHP)**
6. **Manipulate Data Using Data Layer**
